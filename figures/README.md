# Figure sources

Figures are generated by `tools/plot_results.py` from `results/eval_summary.json` and `results/paired_analysis.json`. Those reports were supplied by the user after running the experiment in Ubuntu. No new episodes or model calls are used for plotting.

- `overview`: memory records, success rate, decisions, and solver tokens.
- `task_types`: six task-type success counts, 50 tasks per type.
- `paired_uncertainty`: reported C minus A differences and 95% paired bootstrap intervals.
- `paired_outcomes`: the four possible paired success/failure outcomes.

Each figure is available as SVG for the README and PNG for downloading. All bar charts start at zero. The difference plots use their own units; do not compare their line lengths across panels.

The script reads the supplied intervals; it does not recompute them from episode logs. The counts and means can be checked against the public JSON. Repeated-stage compression and retrieval speed were not measured in this run.
